# POL-004 Bundled services and component codes

> Synthetic policy written for this prototype. Not a real payer policy.

When a comprehensive code and one of its component codes are billed for the same member, provider and date, only the comprehensive code is payable unless the edit pair allows a modifier and the record supports it.

Public basis to verify: CMS National Correct Coding Initiative (NCCI) Procedure-to-Procedure edits and Policy Manual
