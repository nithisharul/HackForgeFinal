# R1 Duplicate claim

> Reference page written by code from the pipeline. Rebuilt on every change; do not edit by hand.

## What it checks
The same member, provider, procedure code and billed amount appear again within 3 days.

## Threshold
Gap between the two claims of 3 days or less; all four fields must match exactly.

## Reference table
None. The rule compares claims with each other.

## Data used
- `member_id`
- `provider_id`
- `procedure_code`
- `billed_amount`
- `service_datetime`
- Defined in: [[data_claims]]

## Known exceptions
- A corrected resubmission where the original was rejected and never paid
- A procedure repeated on the same day with a repeat-procedure modifier (modifiers are not in this data)

## Patterns it supports
- [[duplicate_billing]] | Duplicate billing

## Regulatory background
- [[REG-CLAIMS]] | Medicare claims processing rules (duplicates, place of service)
