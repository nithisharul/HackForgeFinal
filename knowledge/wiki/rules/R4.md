# R4 Unit limit (MUE)

> Reference page written by code from the pipeline. Rebuilt on every change; do not edit by hand.

## What it checks
The units billed for one code, for one member by one provider on one date, are above the most a provider would plausibly report.

## Threshold
Running total of units for the member, provider, code and date exceeds the code's limit.

## Reference table
240 unit limits: 237 official CMS practitioner MUE values (effective 2026-10-01) plus 3 illustrative limits for equipment codes. Loaded by `backend/pipeline/reference.py`. See [[REG-NCCI]].

## Data used
- `member_id`
- `provider_id`
- `procedure_code`
- `units`
- `service_datetime`
- Defined in: [[data_claims]]

## Known exceptions
- Some limits are per claim line rather than per day, and some can be exceeded with documentation of medical necessity
